## [2026-08-04] 채점 연동 = 브로드캐스트 수동 관찰

대안: ① 브라우저 자동화 ② 서버 능동 제출 ③ MITM 프록시 ④ 확장 트래픽 후킹.
ActionCable 스트림이 커넥션이 아니라 채널 파라미터로 스코프된다는 것을 실측 확인 →
서버가 같은 채널을 구독만 해도 브라우저 결과가 그대로 들어온다.
가로챌 대상이 없으므로 프록시·후킹 불필요. **비용**: 어떤 문제를 열었는지 알려줄 센서 확장이 필요.

## [2026-08-04] 코드 작성은 프로그래머스 웹에서

초기에 로컬 편집기 + 서버 능동 제출로 설계했으나 **문제 탐색·검색·설명 읽기를 CLI 로
재구현하는 것은 프로그래머스가 이미 잘하는 것을 더 나쁘게 만드는 일**이라 뒤집었다.
실전 코딩테스트도 웹 편집기에서 치러지므로 감각에도 맞는다.
로컬 디버깅은 서버가 `Solution.java` + 러너를 생성해 해결.

## [2026-08-04] 벡터 DB · 그래프 DB 기각

문제 689개 · 예상 제출 2,000건 이하 → 전체 임베딩 4MB, 정확 탐색이 밀리초.
더 중요한 이유: 코딩테스트 문제는 표면 서사와 실제 유형이 의도적으로 분리되어 있어
**지문 임베딩이 정확히 반대 축을 잡는다**. AI 태깅이 더 정확한 유사도 축.
원본 텍스트를 모두 보존하므로 필요해지면 나중에 인덱스를 만들면 된다.

## [2026-08-04] AI 디버거 제어 미채택

JetBrains Debugger MCP 로 기술적으로 가능하나, 디버깅을 원한 이유가 "내가 디버그를 찍고 싶어서"였다.
AI 가 디버거를 몰면 **자동완성을 끄기로 한 판단과 정면으로 어긋난다**.
되돌릴 수 없는 결정이 아니므로 필요해지면 별도 MCP 로 붙인다.
