# ps-records

Programmers solving records. Generated by [programmers-tracker](https://github.com/BrokenFinger98/programmers-tracker).

**Open this folder as an Obsidian vault** to browse the dashboard, weakness analysis, and
review queue in a GUI. The only plugin you need is **Dataview**.

| Note | Contents |
|---|---|
| `_dashboard.md` | Recent submissions · today's stats |
| `_weakness.md` | First-submission pass rate per tag · verdict distribution |
| `_review.md` | Review queue |
| `_warmup.md` | Reactivation diagnosis — alive / fuzzy / dead |
| `_exam.md` | Past-exam set progress |

## Structure

```
problems/<lessonId>-<title>/
├── README.md      Server-generated (frontmatter + attempt history). Overwritten every time
├── notes.md       Mistake notes. The server never touches it
├── Solution.java
├── SolutionTest.java   Open in IntelliJ to debug
├── meta.json
└── attempts/      Per-submission code + raw results
log/submissions.jsonl   Full submission log (the raw source MCP reads)
```

⚠️ `.ps/session` is the session cookie. **Never commit it.**
